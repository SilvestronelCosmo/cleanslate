Come creare una Password per le App

Istruzioni passo-passo per Gmail, Outlook, iCloud e Yahoo

🔴 Google / Gmail

Per motivi di sicurezza, Google non consente l'accesso con la tua normale password alle app IMAP. Occorre una password specifica di 16 caratteri:

  1. Apri il link: myaccount.google.com/apppasswords (accedi con il tuo account Google se richiesto).
  2. Assicurati che la Verifica in due passaggi (2FA) sia attiva sul tuo account.
  3. Nel campo nome dell'app, scrivi CleanSlate e clicca su Crea.
  4. Google genererà una password gialla di 16 caratteri (es. abcd efgh ijkl mnop).
  5. Incollala direttamente nel campo App Password di CleanSlate.

🔵 Microsoft Outlook / Hotmail

  1. Accedi a account.live.com/proofs/AppPassword.
  2. Seleziona Crea una nuova password per le app.
  3. Copia la password generata e usa server outlook.office365.com (porta 993).

⚪ Apple iCloud

  1. Accedi a appleid.apple.com.
  2. Vai nella sezione Accesso e sicurezza → Password specifiche per le app.
  3. Genera la password per CleanSlate e usa server imap.mail.me.com (porta 993).

Come funziona la Scansione OSINT

Riconoscimento footprint senza credenziali né accesso all'inbox

La scansione OSINT (Open Source Intelligence) è una tecnica non invasiva:

  • Nessun accesso alla posta: non ti verrà mai chiesta alcuna password o autorizzazione.
  • Interrogazione endpoint pubblici: interroga le API pubbliche di registrazione e validazione usate dai siti web (Twitter, Spotify, Duolingo, GitHub, Gravatar, ecc.).
  • Verifica presenza: quando una piattaforma risponde che l'email è già registrata, CleanSlate la identifica e recupera i link di cancellazione e contatti DPO.
  • Velocità: tutti i controlli vengono eseguiti in parallelo asincrono in circa 3-5 secondi.

Esportazione Offline Google Takeout

Come analizzare la tua posta al 100% offline senza collegare account

  1. Vai su takeout.google.com.
  2. Clicca su Deseleziona tutto e seleziona esclusivamente Posta (Gmail).
  3. Clicca su Passaggio successivo e conferma la creazione dell'archivio.
  4. Una volta scaricato il file .zip, estrai il file .mbox.
  5. Trascina il file .mbox nella schermata di CleanSlate. La scansione avverrà istantaneamente in locale senza nessuna connessione internet.
